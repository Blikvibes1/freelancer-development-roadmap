Week 07 · Modal Dialog

Modals done properly

Focus trap, Escape to close, outside click, restored focus, and smooth enter/exit transitions. Built as a reusable, accessible pattern.

What this implements

  • Focus is trapped inside the open modal
  • Escape key closes the modal
  • Clicking the backdrop closes it
  • Focus returns to the trigger that opened it
  • Body scroll is locked while open
  • Smooth enter / exit animation
  • True Theme Mode support

Project details

This is a fully accessible modal. Try tabbing — focus stays inside. Press Escape or click the backdrop to close. When it closes, focus returns to the button that opened it.
