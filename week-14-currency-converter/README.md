# Flux — Week 14 Currency Converter

Live currency converter using the free Frankfurter API (no key required).

## Design Features Used
- Amount + dual currency selects
- Swap control with rotation micro-interaction
- Live result + rate display
- Status messaging
- Theme Mode (Noir / Lumen)

## Features
- Real-time rates via Frankfurter
- 15+ popular currencies prioritized
- Instant conversion on input/change
- Swap currencies
- Zero dependencies, no API key

## Run
Open `index.html` or `npx serve .` (needs network).
