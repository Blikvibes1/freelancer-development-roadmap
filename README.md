## How to run

**Frontend weeks (02–20):** open `index.html` or `npx serve week-XX-...`

**Backend weeks (21+):**
```bash
cd week-31-jwt-auth
npm install
npm run seed   # if available
npm start
```

See each project’s `README.md` for details.
