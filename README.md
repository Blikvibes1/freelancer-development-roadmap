# Freelancer Development Roadmap

100-week program to build a professional frontend / full-stack freelancer portfolio.

## Structure

Each week is a self-contained, portfolio-quality project.

```
freelancer-development-roadmap/
├── week-02-responsive-navbar/   ← Current
│   ├── index.html
│   ├── style.css
│   ├── script.js
│   └── README.md
└── ...
```

## Completed Projects

| Week | Project                          | Status   |
|------|----------------------------------|----------|
| 02   | Responsive Navbar (Vespera Nav)  | ✅ Done  |

## How to run a project

Open the `index.html` of any week folder in a browser, or serve it with:

```bash
npx serve week-02-responsive-navbar
```
