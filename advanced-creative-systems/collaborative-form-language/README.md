# Morphos — Collaborative Form Language

**Project 14 · Advanced Creative Series**

Designers contribute form primitives (gestural sketches or shape tools). The system analyzes the pool, surfaces an emerging formal language, and generates hybrid forms that feel like natural extensions of the collective input.

---

## Purpose

Emphasize emergence, shared authorship, and the evolution of a visual language over time.

---

## Features

- **Form pool** — Shared primitives with author + tag  
- **Contribute** — Freehand draw, circle, rect, arc tools  
- **Hybrids** — Morph between paired primitives  
- **Language** — Curvature, angularity, density, closure stats + contributor list  
- **localStorage** persistence  
- **Themes**: Atelier · Slate · Chalk  
- Zero build step  

---

## How to Run

1. Open `index.html`.  
2. Browse the seed pool.  
3. Contribute a drawn or placed form.  
4. Generate hybrids; inspect the emerging language.

---

## Technical Notes

- Path interpolation for hybrids  
- Angle-based curvature / angularity metrics  
- Client-side only  
- No frameworks
