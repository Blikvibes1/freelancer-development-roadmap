# Gestura — Gesture Language Inventor

**Project 18 · Advanced Creative Series**

Invent a personal gestural vocabulary. Draw gestures, capture multiple samples, bind meanings, recognize live, and see the language as a meaning map.

---

## Purpose

Expressiveness, reliability, and the feeling of creating a private language. Pointer/touch based for consistent recognition without webcam dependency.

---

## Features

- **Studio** — Draw · capture samples · name · map to meaning  
- **$1-style recognizer** — Resample, rotate, scale, template distance  
- **Live recognize** — Draw on the small pad to match lexicon entries  
- **Lexicon** — Browse, inspect samples, remove  
- **Meaning map** — Spatial view of the vocabulary  
- **localStorage** persistence  
- **Themes**: Signal · Ink · Void  
- Zero build step  

---

## How to Run

1. Open `index.html`.  
2. Draw a gesture → **Capture sample** (repeat 2–3 times).  
3. Name it, assign a meaning → **Save to lexicon**.  
4. Use **Live recognize** to test. Browse **Lexicon** and **Map**.

---

## Technical Notes

- No webcam required (reliable across environments)  
- Client-side geometric recognition  
- No frameworks
