# Axiom — Value Alignment Playground

**Project 21 · Advanced Creative Series**

Define ethical principles, then face scenarios that force them into conflict. Choices reveal which values actually win — not as moral judgment, but as clearer self-understanding.

---

## Purpose

Structured confrontation of value hierarchies. No moralizing; only trade-offs made visible.

---

## Features

- **Value set** — presets + custom entries  
- **Confrontation** — generated scenarios pairing two values  
- **Forced choice** — A vs B, no neutral  
- **Revealed hierarchy** — win counts and decision log  
- **localStorage** persistence  
- **Themes**: Tribunal · Study · Void  
- Zero build step  

---

## How to Run

1. Open `index.html`.  
2. Select at least two values.  
3. **Begin confrontation** and choose under pressure.  
4. Review the map; run more scenarios to refine the ranking.

---

## Technical Notes

- Template-based scenario generation  
- Pairwise value conflicts  
- No frameworks
