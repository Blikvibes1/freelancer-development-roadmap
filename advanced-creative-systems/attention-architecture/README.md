# Attentos — Attention Architecture

**Project 17 · Advanced Creative Series**

An adaptive interface that models real-time attention from pointer stillness, scroll dynamics, and keystroke rhythm—then reshapes itself toward calm, focus, or flow. Protects attention rather than demanding it.

---

## Purpose

Long-term cognitive sustainability. No webcam, no content inspection—only behavioral rhythm, used gently.

---

## Features

- **Signals** — Pointer stillness, scroll chaos, keystroke steadiness, idle depth  
- **Modes**
  - **Calm** — Softened chrome, more space, when idle or scattered  
  - **Focus** — Side panel hides, locked surface, when typing is steady  
  - **Flow** — Fluid feedback when interaction is continuous and light  
- **Attention meter** + session timer  
- **Themes**: Calm · Focus · Flow  
- `prefers-reduced-motion` respected  
- Zero build step  

---

## How to Run

1. Open `index.html`.  
2. Type steadily in the work surface → Focus mode.  
3. Pause for a while → Calm.  
4. Scroll and move fluidly → Flow signals.

---

## Technical Notes

- Client-side only; no camera APIs  
- Rolling windows for key intervals and scroll deltas  
- Mode selection with soft thresholds  
- No frameworks
