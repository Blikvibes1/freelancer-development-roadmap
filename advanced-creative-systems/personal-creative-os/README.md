# Atelier — Personal Creative OS

**Project 26 · Advanced Creative Series**

A responsive environment shaped around one person’s creative mind: energy rhythms, deep-work protection, reference surfacing, and a momentum trail — not a generic productivity app.

---

## Purpose

Protect deep work, surface the right references for current energy, and leave a light trail of what moved — so long-term creative momentum stays visible.

---

## Features

- **Energy log** — drained → peak; rhythm chart from recent checks  
- **Deep work** — intention + timer; focus mode quiets other panels  
- **Reference shelf** — craft / spark / method / rest; surfaced by energy  
- **Momentum marks** — short trail, not a task list  
- **localStorage** persistence  
- **Themes**: Atelier · Night · Paper  
- Zero build step  

---

## How to Run

1. Open `index.html`.  
2. Log energy; add references and momentum marks.  
3. Start a focus block when you need protection.

---

## Technical Notes

- Vanilla HTML/CSS/JS  
- Focus mode via `data-mode`  
- No frameworks
