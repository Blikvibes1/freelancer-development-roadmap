# Loci — Memory Palace Builder

**Project 9 · Advanced Creative Series**

A spatial mnemonic tool for encoding real information as vivid images placed in architectural rooms, then testing long-term retention through spatial recall.

---

## Purpose

Combine the classical art of memory with interactive design. Users build rooms, place emotionally charged images at loci, and walk the palace in recall exercises.

---

## Features

- **Palace view** — Floor-plan canvas of rooms; click to enter; loci as points  
- **Encode** — Fact + vivid image + emotion + room placement  
- **Recall** — Spatial prompts (“You enter the Library. You see…”); check / reveal  
- **Guide** — Six principles of effective memory palace use  
- **Add rooms** — Expand the palace  
- **localStorage** persistence  
- **Themes**: Atrium · Archive · Night  
- Zero build step  

---

## How to Run

1. Open `index.html`.  
2. Explore default rooms on the Palace canvas.  
3. Encode a fact with a bizarre, emotional image.  
4. See the locus appear in the room.  
5. Use **Recall** to test retrieval.  
6. Read **Guide** for technique tips.

---

## Technical Notes

- Canvas 2D spatial layout (reliable without WebGL)  
- Client-side only  
- Simple recall scoring via keyword overlap  
- No frameworks
