# Myth Loom — Collaborative Myth-Weaving Platform

**Project 8 · Advanced Creative Series**

A shared mythological world built from fragments: characters, places, events, rules, and artifacts. Contributors add threads; the loom integrates them, flags tension, and tracks influence.

---

## Purpose

Feel like participating in a living collective imagination. See the evolving structure of the world and the weight of different weavers.

---

## Features

- **World browser** — Filter by fragment type; tension badges on conflicting rules  
- **Contribute** — Add fragments with optional links to existing ones  
- **Integration** — Automatic tension detection (rule conflicts, opposing keywords)  
- **Structure graph** — Canvas map of links (solid) and tension (dashed)  
- **Contributors** — Influence by fragment count + inbound links  
- **Seed world** — The Salt Choir and its mythos  
- **localStorage** persistence  
- **Themes**: Loom · Ink · Gild  
- Zero build step  

---

## How to Run

1. Open `index.html`.  
2. Explore the World; filter by type.  
3. Contribute a fragment (name yourself as weaver).  
4. Open Structure to see links and tension edges.  
5. Open Contributors for influence ranking.

---

## Technical Notes

- Client-side only (simulates multi-user via named contributors)  
- Keyword / rule-pair tension detection  
- Canvas graph layout  
- No frameworks
