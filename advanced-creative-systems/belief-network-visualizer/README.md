# Doctrine — Belief Network Visualizer

**Project 23 · Advanced Creative Series**

Map a belief system as interconnected architecture. Reveal load-bearing beliefs, supporting assumptions, contradictions, and leverage points for change.

---

## Purpose

Treat beliefs as structure, not isolated opinions. Support individual reflection; structure also enables comparative analysis across saved networks.

---

## Features

- **Force-directed map** — drag nodes; support vs contradiction edges  
- **Load-bearing detection** — weight × connectivity  
- **Edit** — add beliefs, supports, contradictions  
- **Insights** — ranked load-bearing, contradiction list, leverage points  
- **Sample network** included  
- **localStorage** persistence  
- **Themes**: Slate · Parchment · Ink  
- Zero build step  

---

## How to Run

1. Open `index.html`.  
2. Explore the sample map; click nodes for detail.  
3. **Edit** to add beliefs and links.  
4. **Insights** for structural summary.

---

## Technical Notes

- Simple force layout (repulsion + springs)  
- Load-bearing = felt weight + support degree  
- Leverage = central nodes and contradiction boundaries  
- No frameworks
