# Chronos — Temporal Interface

**Project 16 · Advanced Creative Series**

An interface that exists across multiple timescales. Scrub from deep past to far future. Present commits ripple forward; past is a read-only echo; future accepts annotations without rewriting history.

---

## Purpose

Explore what becomes possible when an interface is not confined to a single moment. Conceptual clarity and experiential impact over technical spectacle.

---

## Features

- **Timeline scrubber** — T−5 … Present … T+5  
- **Shared ledger** — Entries with birth time and kind (commit / annotation)  
- **Past** — Read-only; see what was true before later edits  
- **Present** — Full write; commits appear in all future views  
- **Future** — Annotations for that moment; present commits shown as ripples  
- **localStorage** persistence  
- **Themes**: Chrono · Archive · Signal  
- Zero build step  

---

## How to Run

1. Open `index.html`.  
2. Scrub the timeline. Notice what appears and what is locked.  
3. Commit at present; scrub forward to see the ripple.  
4. Annotate a future moment; return to present to see it as a projection.

---

## Technical Notes

- Explicit visibility rules by timescale
