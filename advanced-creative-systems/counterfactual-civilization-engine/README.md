# Fork — Counterfactual Civilization Engine

**Project 24 · Advanced Creative Series**

Start from alternate early conditions and evolve long-term trajectories of technology, social organization, culture, and knowledge. Emphasizes path dependence and insight over spectacle.

---

## Purpose

Show how small differences in environment, resources, founding organization, and knowledge bias compound across eras — including shocks and brittle couplings.

---

## Features

- **Seed** — environment, resources, organization, knowledge bias, shock intensity  
- **Five eras** — foundation → late form with axis scores  
- **Chart** — tech · social · culture · knowledge over time  
- **Late-form synthesis** + structural insights  
- **Compare** — save runs to contrast path dependence  
- **Themes**: Chronicle · Atlas · Ash  
- Zero build step  

---

## How to Run

1. Open `index.html`.  
2. Set early conditions.  
3. **Evolve civilization**.  
4. Read eras and late form; optionally save to Compare.

---

## Technical Notes

- Seeded path-dependent simulation  
- Cross-axis coupling (e.g. high social / low knowledge brittleness)  
- No frameworks
