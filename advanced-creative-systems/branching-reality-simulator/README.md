# Divergence — Branching Reality Simulator

**Project 6 · Advanced Creative Series**

Create and explore alternate versions of historical, personal, or technological events. Define a divergence point; the system cascades plausible long-term consequences across technology, society, culture, and personal life.

---

## Purpose

Emphasize plausible causality and emergent complexity rather than pure fantasy. Results appear as branching timelines that can be inspected node by node.

---

## Features

- **Scenario types** — Historical · Personal · Technological  
- **Curated divergence points** with baseline context  
- **Custom fork description** — what changes at the moment of split  
- **Horizon** — 20 / 50 / 100 years  
- **Branching depth** — 3–5 levels  
- **Interactive timeline** — color-coded domains, clickable nodes  
- **Inspect panel** — year, domain, consequence text, causal link  
- **Seeded generation** — consistent results for same inputs  
- **Themes**: Chronicle · Parchment · Signal  
- Zero build step

---

## How to Run

1. Open `index.html`.  
2. Choose scenario type and divergence point.  
3. Optionally describe what changes at the fork.  
4. Set horizon and depth → **Simulate branches**.  
5. Click nodes on the timeline to inspect consequences.

---

## Technical Notes

- Client-side generative model (template + domain cascades)  
- Seeded PRNG for reproducibility  
- Canvas 2D hierarchical layout with bezier edges
