# Densitas — Meaning Compression Tool

**Project 25 · Advanced Creative Series**

Progressively compress complex text into denser symbolic forms while tracking meaning integrity — until collapse.

---

## Purpose

Explore the limits of compression: how far can meaning be densified before it fails? Four aesthetics shape the path down.

---

## Features

- **Source input** — experiences, paragraphs, notes  
- **Aesthetics**: poetic · diagrammatic · mathematical · ritualistic  
- **Depth** 1–6 (gentle → collapse edge)  
- **Layer stack** with token counts and integrity %  
- **Meaning integrity meter**  
- **Themes**: Cipher · Vellum · Terminal  
- Zero build step  

---

## How to Run

1. Open `index.html`.  
2. Paste text or **Load sample**.  
3. Choose aesthetic and depth.  
4. **Compress** and read the layers.

---

## Technical Notes

- Rule-based densification per aesthetic  
- Integrity curve declines nonlinearly with depth  
- No frameworks
