# Style Lab — Controlled Mutation

**Project 12 · Advanced Creative Series**

Model a creator’s core artistic voice, then generate controlled mutations at a chosen distance. Compare origin vs mutation and see which traits held or drifted.

---

## Purpose

Help creators expand aesthetic range without losing their core voice. Clear controls for how far to push; transparent relationship between original style and new directions.

---

## Features

- **Voice** — Palette, form, density, contrast, gesture, mood  
- **Live origin signature** preview  
- **Mutation distance** slider (0% = adjacent, 100% = far)  
- **Six mutations** per run, each seeded  
- **Compare** — side-by-side origin vs mutation with trait drift table  
- **Themes**: Atelier · Gallery · Darkroom  
- Zero build step  

---

## How to Run

1. Open `index.html`.  
2. Set voice traits; watch the origin signature.  
3. **Lock voice & open Mutate**.  
4. Set distance → **Generate mutations**.  
5. Click a mutation → **Compare** for drift analysis.

---

## Technical Notes

- Style parameters map to generative visual rules  
- Seeded rendering for reproducibility  
- Drift measured per trait (sat, organic, density, contrast, gesture, hue)  
- No frameworks
