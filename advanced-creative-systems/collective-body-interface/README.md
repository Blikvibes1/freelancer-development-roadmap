# Corpus — Collective Body Interface

**Project 20 · Advanced Creative Series**

Multiple people (or roles) simultaneously drive a single shared digital organism. Alignment moves it cleanly; conflict fractures and slows it. Coherence makes the quality of collective attention visible.

---

## Purpose

Explore coordination, shared intention, leadership, and emergent group behavior through a tangible shared body.

---

## Features

- **Four local agents** — Alpha (WASD), Beta (IJKL), Gamma (arrows), Delta (TFGH)  
- **Pad drag** — touch/mouse force vectors per agent  
- **Coherence meter** — agreement × participation × optional voice  
- **Leadership** — who pulls hardest when others are weak  
- **Voice energy** — optional mic contributes to body scale and coherence  
- **Themes**: Hive · Chorus · Pulse  
- Zero build step  

---

## How to Run

1. Open `index.html`.  
2. One or more people take agent pads (keys or drag).  
3. Pull in the same direction → high coherence, smooth motion.  
4. Pull against each other → low coherence, damped motion.  
5. Optional: enable voice energy.

---

## Technical Notes

- Vector agreement + participation → coherence  
- Conflict damps velocity; alignment amplifies  
- No frameworks; Web Audio Analyser for mic
