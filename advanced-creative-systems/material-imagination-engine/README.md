# Speculum — Material Imagination Engine

**Project 13 · Advanced Creative Series**

Generate visualizations and dossiers of impossible or speculative materials from poetic descriptions. Balances physical plausibility with imaginative freedom.

---

## Purpose

Suitable for concept design, storytelling, and speculative research. Describe a material in language; receive a specimen visualization and a structured dossier.

---

## Features

- **Compose** — Free-text poetic prompt + preset examples  
- **Keyword extraction** — Metal, glass, ceramic, textile, vapor, etc.  
- **Behavior detection** — Memory, acoustic, kintsugi, optical, hydrous, thermal…  
- **Specimen view** — Animated canvas rendering by material class  
- **Dossier** — Physical notes, behaviors, speculative uses  
- **Themes**: Forge · Lab · Cabinet  
- Zero build step  

---

## How to Run

1. Open `index.html`.  
2. Type a description or pick a preset.  
3. **Imagine specimen**.  
4. Explore the specimen and open the dossier.

---

## Technical Notes

- Rule-based NLP (keywords + behavior regex)  
- Canvas 2D material rendering  
- No frameworks
