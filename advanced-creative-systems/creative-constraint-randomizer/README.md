# Constraint Forge — Productive Limits

**Project 15 · Advanced Creative Series**

An intelligent creative constraint generator that produces high-quality, non-generic limits tailored to domain, goal, and difficulty. Rate constraints to improve what the forge serves you.

---

## Purpose

Avoid clichés. Offer constraints that productively limit the design space while opening unexpected directions.

---

## Features

- **Domains** — Visual · Writing · Product · Music · Code  
- **Difficulty** — Gentle · Firm · Severe  
- **Goal field** — Soft bias toward relevant constraints  
- **Avoid clichés** toggle  
- **Why** explanation for every constraint  
- **1–5 usefulness rating** → history + profile learning  
- **Themes**: Forge · Studio · Ink  
- Zero build step  

---

## How to Run

1. Open `index.html`.  
2. Choose domain, goal, difficulty.  
3. **Forge constraint**.  
4. Rate it. Over time, History and Profile reflect what works for you.

---

## Technical Notes

- Curated constraint banks (not random word salad)  
- Recent-use avoidance + rating-based domain preference  
- localStorage for history and preferences  
- No frameworks
