# Dramatic Field — Narrative Particle System

**Project 10 · Advanced Creative Series**

Stories as dynamic particles. Characters, themes, conflicts, and emotions attract, repel, and pulse according to dramatic relationships.

---

## Purpose

Make abstract narrative dynamics visible and felt. Seed elements, tune forces, pulse tension, watch structure emerge.

---

## Features

- **Particle types** — Character · Theme · Conflict · Emotion  
- **Forces**
  - Themes attract characters and each other  
  - Conflicts repel (especially characters)  
  - Emotions pulse and soft-attract  
- **Seed** — Add custom particles with dramatic charge  
- **Sample story** — Exile / Crown / Belonging / Betrayal preset  
- **Pulse tension** — Inject energy into conflict & emotion particles  
- **Force sliders** — Attraction, repulsion, damping, emotion pulse  
- **Live tension HUD**  
- **Themes**: Drama · Ink · Neon  
- Zero build step  

---

## How to Run

1. Open `index.html` (sample story loads automatically).  
2. Watch clusters form; conflicts push away.  
3. **Pulse tension** to agitate the field.  
4. Seed new particles or adjust Forces.  
5. Clear field to start empty.

---

## Technical Notes

- Canvas 2D particle physics  
- Pairwise forces + soft collision + center gravity  
- `prefers-reduced-motion` freezes physics  
- No frameworks
