# Inner Life — Character Consciousness Engine

**Project 7 · Advanced Creative Series**

Persistent characters with memory, evolving beliefs, internal contradictions, and gradual personality change. Interact over multiple sessions; state survives in localStorage.

---

## Purpose

Psychological depth and continuity over short-term cleverness. Characters remember prior talks, form opinions about the user, develop goals, and occasionally reveal private tension.

---

## Features

- **Dialogue** — Multi-character chat with persistent memory  
- **Mind view** — Beliefs (with strength), tension, goals, mood, opinion of user, memory traces  
- **Create** — Seed name, temperament, core belief, private contradiction  
- **Temperaments** — Warm · Reserved · Volatile · Analytical (distinct voice patterns)  
- **Dynamics**
  - Opinion of user shifts with tone  
  - Beliefs strengthen when touched in conversation  
  - Mood drifts  
  - Goals evolve every few exchanges  
  - Occasional system notes on internal change  
- **Themes**: Inward · Clinic · Theater  
- Zero build step; fully client-side  

---

## How to Run

1. Open `index.html`.  
2. Select Maris or Corvin (or create a new character).  
3. Speak — responses reference beliefs, memory, and tension.  
4. Open **Mind** to inspect the inner landscape.  
5. Return later; localStorage keeps continuity.

---

## Technical Notes

- Rule-based response generation (not an LLM API)  
- localStorage persistence  
- Cap on memory length for performance  
- No frameworks
