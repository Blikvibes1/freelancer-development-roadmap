# Constraint Studio — Design by Rules

**Project 11 · Advanced Creative Series**

A visual environment where designers define creative constraints (palette, geometry, layout) rather than drawing directly. The system explores the possibility space and generates variations that satisfy every rule.

---

## Purpose

Think in rules, relationships, and boundaries. The link between constraints and outcomes stays transparent and controllable.

---

## Features

- **Constraints**
  - Palette: hue family, max colors, saturation ceiling  
  - Geometry: shape family, density, scale variance  
  - Layout: margin, alignment (free / grid / radial), overlap policy  
- **Live preview** updates as rules change  
- **Explore space** — 12 seeded variations that all obey constraints  
- **Gallery + Inspect** — full constraint dump per variation  
- **Themes**: Studio · Paper · Terminal  
- Zero build step  

---

## How to Run

1. Open `index.html`.  
2. Adjust constraints; watch the live preview.  
3. Click **Explore space** for 12 variations.  
4. Open any card in Gallery → Inspect to see which rules it satisfied.

---

## Technical Notes

- Seeded composition engine (palette + layout + shapes)  
- Overlap resolution when disallowed  
- Canvas rendering  
- No frameworks
