# Match — Week 19 Memory Card Game

Flip-card matching game with move counter, timer, and win-state overlay.

## Purpose

Week 19 of the Freelancer 100-week development program.  
Roadmap requirement: **Memory Card Game — flip-card matching with move counter, timer, and win-state logic.**

## Design Features Used
(from FRONT-END-DESIGN-FEATURES.txt)

- 3D card flip (CSS preserve-3d)
- Game HUD (moves, time, pairs)
- Win overlay with stats
- Matched-state styling
- Theme-aware card backs and surfaces
- Micro-interactions on flip and buttons

## Features

- 16 cards / 8 pairs
- Flip animation
- Move counter
- Elapsed timer (starts on first flip)
- Pair progress
- Win overlay with final stats
- Restart / Play again
- True Theme Mode (Noir / Lumen)
- Keyboard-focusable cards
- Reduced-motion support
- Zero dependencies

## How to Run

Open `index.html` or:

```bash
npx serve .
```
