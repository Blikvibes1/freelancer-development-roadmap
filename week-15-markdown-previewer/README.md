# Ink — Week 15 Markdown Previewer

Split-screen Markdown editor with live HTML preview. Lightweight custom parser (no libraries).

## Design Features Used
- Split-pane workspace
- Monospace editor
- Styled preview (headings, lists, code, quotes)
- Theme Mode (Noir / Lumen)

## Features
- Live render as you type
- Headings, bold, italic, code, links, lists, blockquotes, hr
- No external Markdown library
- True Theme Mode

## Run
Open `index.html` or `npx serve .`
