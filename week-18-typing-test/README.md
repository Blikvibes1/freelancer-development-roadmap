# Typeflow — Week 18 Typing Speed Test

WPM calculator with live accuracy, error highlighting, and passage rotation.

## Design Features Used
- Live stats strip (WPM, accuracy, errors, time)
- Character-level correct / wrong / current highlighting
- Monospace passage + input
- Restart / new passage actions
- Theme Mode (Noir / Lumen)

## Features
- Real-time WPM and accuracy
- Error count and per-character feedback
- Multiple practice passages
- Paste disabled (keeps it honest)
- Zero dependencies

## Run
Open `index.html` or `npx serve .`
