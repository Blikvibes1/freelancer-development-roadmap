# Signal — Week 16 QR Code Generator

Generate downloadable QR codes from text or URLs. Theme-aware colors.

## Design Features Used
- Textarea input
- Generate + download actions
- Canvas QR preview
- Theme Mode (Noir / Lumen) with matching QR colors

## Features
- Any text or URL → QR
- PNG download
- Theme-colored modules
- Uses `qrcode` library via CDN

## Run
Open `index.html` (needs network once for CDN) or `npx serve .`
