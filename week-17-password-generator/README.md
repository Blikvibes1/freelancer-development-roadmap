# Vault — Week 17 Password Generator

Secure password generator with length slider, character options, strength meter, and one-click copy.

## Design Features Used
- Password output + copy button
- Strength bar (weak / fair / strong)
- Length range slider
- Character option checkboxes
- Theme Mode (Noir / Lumen)

## Features
- Length 8–64
- Uppercase, lowercase, numbers, symbols
- Guarantees at least one of each selected type
- Uses `crypto.getRandomValues` when available
- Strength estimate
- Clipboard copy

## Run
Open `index.html` or `npx serve .`
